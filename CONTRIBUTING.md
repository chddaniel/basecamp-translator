# Contributing

Thanks for helping another team avoid doing this work again.

For bugs, include the behavior you expected, a redacted example, and whether it
concerns a to-do title, description, or comment. Do not include credentials,
private URLs, names, screenshots, or message content without permission.

For code changes, run `npm ci`, `npm run check`, and `npm test`. Tests mock
Basecamp and Google; no live accounts or paid requests are required. Keep new
features within to-dos/comments unless discussed first. Supported languages come
from Google's NMT catalog; changes to language routing need parsing, detection,
setup, and regression coverage, not just a new label.

Contributions are under the repository's MIT license. Support is best-effort.
